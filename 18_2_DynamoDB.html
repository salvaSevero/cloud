    DynamoDB

    DynamoDB es un servicio de base de datos NoSQL claves:valor.

    DynamoDB está diseñado para aplicaciones que necesitan responder rápidamente a numerosas peticiones, incluso cuando aumenta considerablemente el volumen de información o el número de usuarios.

    Ejemplos de uso:¶

    • Aplicaciones web y móviles que almacenan perfiles de usuario.
    • Catálogos de productos y carritos de compra.
    • Aplicaciones de videojuegos que guardan puntuaciones y progresos.
    • Sistemas IoT que reciben información de sensores.
    • Aplicaciones sin servidor que utilizan AWS Lambda y API Gateway.

    Características.¶

    • Servicio administrado: AWS se encarga de la infraestructura y no es necesario instalar ni administrar un servidor de base de datos.

    • Escalabilidad y Baja latencia: Escala automáticamente bajo demanda o bajo previsión de trabajo.

    • Alta Disponibilidad: Permite replicación entre zonas/regiones.

    Componentes.¶

    Una base de datos en DynamoDB se compone de:

    • Tablas: son conjuntos de datos, formada por los elementos.
    • Elementos: grupo de atributos que pueden identificar de forma exclusiva a un registro.
    • Atributos: elementos de datos fundamental que no es preciso seguir dividiendo.

    Cada elemento de una tabla no puede superar los 400KB.

    DynamoDB soporta dos tipos de claves principales:

    • Clave de partición es una clave principal simple.
    • Clave de partición compuesta formada por dos atributos: Clave de Partición + Clave de Ordenación.

    A medida que aumenta el volumen de datos, la clave principal particiona e indexa los datos de la tabla.

    Comandos y Atributos.¶

    Comandos.¶

    Operación Descripción
    GetItem Busca un elemento concreto mediante su clave primaria.
    Query Recupera varios elementos utilizando obligatoriamente la clave de partición y, opcionalmente, condiciones sobre la clave de ordenación.
    Scan Recorre toda la tabla y permite filtrar por atributos que no son claves.
    PutItem Inserta un elemento nuevo. Si ya existe otro con la misma clave primaria, lo reemplaza.
    UpdateItem Modifica los atributos de un elemento existente.
    DeleteItem Elimina un elemento de la tabla.

    Tipos de Atributos.¶

    Tipo Descripción
    S Cadena de texto (String).
    N Número (Number).
    BOOL Valor booleano (Boolean): true o false.
    M Mapa de atributos (Map).
    L Lista de elementos (List).
    SS Conjunto de cadenas de texto (String Set).

    Ejemplos¶

    aws dynamodb put-item \
  --table-name PerfilesAlumnos \
  --item '{
    "alumnoId": {"S": "A001"},
    "nombre": {"S": "Ana"},
    "ciclo": {"S": "SMR"},
    "curso": {"N": "1"},
    "email": {"S": "ana@example.com"}
  }'

aws dynamodb get-item \
  --table-name PerfilesAlumnos \
  --key '{"alumnoId":{"S":"A001"}}'

aws dynamodb scan \
  --table-name PerfilesAlumnos \
  --filter-expression "ciclo = :ciclo" \
  --expression-attribute-values '{":ciclo":{"S":"SMR"}}'

aws dynamodb update-item \
  --table-name PerfilesAlumnos \
  --key '{"alumnoId":{"S":"A001"}}' \
  --update-expression "SET curso = :curso" \
  --condition-expression "attribute_exists(alumnoId)" \
  --expression-attribute-values '{":curso":{"N":"2"}}'
